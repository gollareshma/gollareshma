### 📌 Featured projects

#### 🎥 [AI Video Intelligence](https://github.com/gollareshma/AI_Video_Intelligence)

Search hours of CCTV footage in plain language — typed or spoken. Detection and tracking cut the video into
entity-centric clips, captioning and CLIP embeddings make them searchable, and a LangGraph agent returns
the matching clips cut at the right timestamp. Benchmarked at 15.1% t-IoU against 13.6% for the published
baseline, running on a single T4.

`Python` `PyTorch` `YOLOv8` `LangGraph` `FastAPI` `ChromaDB` `PostgreSQL` `Docker`

---

#### ☸️ [Kubernetes Voting App](https://github.com/gollareshma/K8s-voting-app)

Took an existing microservices voting app and built the full operational layer around it — CI/CD,
autoscaling, zero-trust network policies, Prometheus and Grafana monitoring, and five documented chaos
experiments with written post-mortems.

`Kubernetes` `GitHub Actions` `Prometheus` `Grafana` `Docker`

> Application code forked from [N4si/K8s-voting-app](https://github.com/N4si/K8s-voting-app).
> My work is the Kubernetes manifests, pipeline, monitoring, and resilience testing.

---

#### 🔄 [Employee API — CI/CD](https://github.com/gollareshma/employee-api-cicd)

A Flask REST API with JWT authentication, containerised and delivered through a Jenkins pipeline on AWS
EC2 — checkout, install, launch, test, report.

`Flask` `Jenkins` `Docker` `MySQL` `AWS EC2`

---

#### 🐧 [LAMP Stack DevOps](https://github.com/gollareshma/lamp-stack-devops-project)

Provisioning a full LAMP stack two ways — a Bash script versus an idempotent Ansible playbook — to show
the difference between scripting a server and declaring one.

`Ansible` `Bash` `AWS EC2` `Apache` `MySQL`

---

#### 🛒 [Instacart Market Basket Analysis](https://github.com/gollareshma/Instacart-Market-Basket-Analysis)

Behavioural analysis of 3.4 million grocery orders from 206,000 customers. The clearest finding: reorder
rates jump 27 percentage points between a customer's first ten orders and their eleventh through twentieth
— which is where retention effort actually pays.

`Python` `pandas` `NumPy` `Matplotlib` `Seaborn`
