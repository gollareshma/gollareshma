## About

I build things end to end — not just the model or the endpoint, but the pipeline that ships it, the
monitoring that watches it, and the failure testing that proves it holds up. That interest has pulled me
across three areas that usually stay separate: **machine learning**, **backend services**, and the
**infrastructure** underneath both.

Most of what's here reflects that. A video retrieval system benchmarked against published baselines. A
microservices deployment with chaos experiments and written post-mortems. A CI/CD pipeline that actually
runs. I'd rather have one project that survives contact with reality than five that work on my laptop.

## Featured Projects

### 🎥 [AI Video Intelligence](https://github.com/gollareshma/AI_Video_Intelligence)

**Search hours of CCTV footage in plain language — typed or spoken.**

Most surveillance footage is empty, so the system prunes cheaply before doing anything expensive.
Detection and tracking cut long video into entity-centric clips; captioning and CLIP embeddings make them
searchable; a LangGraph agent decomposes the query, searches across cameras, and applies temporal filters
to return the matching clip cut at the right timestamp.

**15.1% t-IoU** and **70.4% Top-K** on ForeSeaQA, against 13.6 / 66.0 for the published baseline — running
on a single T4, with no video-LLM inference anywhere in the pipeline.

`Python` · `PyTorch` · `YOLOv8` · `ByteTrack` · `CLIP` · `LangGraph` · `FastAPI` · `ChromaDB` · `PostgreSQL` · `Docker`

### ☸️ [Kubernetes Voting App](https://github.com/gollareshma/K8s-voting-app)

**A microservices app, plus the operational layer that makes it survivable.**

Five services on Kubernetes with CI/CD, horizontal autoscaling, zero-trust network policies between
services, centralised logging, and Prometheus/Grafana dashboards. Then five chaos experiments — pod kills,
network partitions, resource starvation — each with a written post-mortem, scoring 8.5/10 on resilience.

`Kubernetes` · `GitHub Actions` · `Docker` · `Prometheus` · `Grafana`

> Application code forked from [N4si/K8s-voting-app](https://github.com/N4si/K8s-voting-app).
> My contribution is the manifests, pipeline, network policies, monitoring, and resilience testing.

<br>

### 🔄 [Employee API — CI/CD](https://github.com/gollareshma/employee-api-cicd)

**A REST API and the pipeline that delivers it.**

Flask API with JWT authentication and MySQL persistence, containerised and shipped through a Jenkins
pipeline on AWS EC2 — checkout, install, launch, test, report. Built to understand what a delivery pipeline
actually does, rather than treating it as a black box.

`Flask` · `Jenkins` · `Docker` · `MySQL` · `AWS EC2`

<br>

### 🐧 [LAMP Stack DevOps](https://github.com/gollareshma/lamp-stack-devops-project)

**The same server, provisioned two ways.**

A full LAMP stack built first with a Bash script, then with an idempotent Ansible playbook — a direct
comparison of scripting a server versus declaring one. Run the script twice and it breaks; run the playbook
twice and nothing changes. That difference is the whole point.

`Ansible` · `Bash` · `AWS EC2` · `Apache` · `MySQL`

<br>

### 🛒 [Instacart Market Basket Analysis](https://github.com/gollareshma/Instacart-Market-Basket-Analysis)

**3.4 million grocery orders, 206,000 customers, one useful finding.**

Reorder rates jump **27 percentage points** between a customer's first ten orders and their eleventh
through twentieth, then flatten out. Attrition peaks just before that window. Together those say something
specific: retention effort spent on the first ten orders is worth more than the same effort spent anywhere
later.

`Python` · `pandas` · `NumPy` · `Matplotlib` · `Seaborn`
